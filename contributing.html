Contributing

Run LightKeeper's own tests from your IDE.

Use this setup when developing LightKeeper's framework, Maven plugin, or runtime agent. If you are testing your own Minecraft plugin, follow Getting Started and the IDE setup guide.

Build local artifacts and prepare a runtime

Use Java 21+, Maven 3.9+, and Linux or macOS. Run these commands from the LightKeeper repository root. Install the current plugin, framework, agent, and fixture before invoking the preparation goal directly:

mvn -pl lightkeeper-integration-tests -am install \
  -DskipTests -DskipITs -Dlightkeeper.skip=true -Dmaven.javadoc.skip=true
mvn -pl lightkeeper-integration-tests \
  lightkeeper:prepare-server@prepare-server-paper -Dlightkeeper.ide=true

Replace prepare-server-paper with prepare-server-spigot to select Spigot. The execution supplies platform identity; lightkeeper.expectedServerType is only a Failsafe assertion input.

Check for Created IDE test setup or Reused IDE test setup, then run a JUnit test from lightkeeper-integration-tests using the IDE gutter button.

After changing LightKeeper

Test-only changes need ordinary IDE compilation. After changing packaged framework, plugin, or agent code, rebuild and install the affected artifacts and repeat preparation. Rebuild the runtime agent after changes requiring new agent or protocol behavior.

See IDE Testing for runtime persistence, refresh, and troubleshooting.
