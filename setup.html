Check setup before starting Minecraft

mvn lightkeeper:doctor

Doctor inspects the effective selected modules: Maven/Java, server configuration, producer guards, plugin-under-test selection, Failsafe skips and IDE ownership metadata. It reports concrete errors and next actions without running build phases, downloading a server or writing project files. Maven may resolve the doctor plugin itself. An unbuilt plugin or missing first-run metadata is a warning: run normal verify once.

Run the copied test with Maven first, then use the ordinary JUnit run button as described in the IDE guide. Native Windows transport remains unverified.
