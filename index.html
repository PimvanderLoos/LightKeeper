BlockPlacementIT.javaJava / JUnit
import nl.pim16aap2.lightkeeper.framework.ILightkeeperFramework;
import nl.pim16aap2.lightkeeper.framework.LightkeeperExtension;
import org.junit.jupiter.api.Test;
import org.junit.jupiter.api.extension.ExtendWith;
import static nl.pim16aap2.lightkeeper.framework.assertions.LightkeeperAssertions.assertThat;

@ExtendWith(LightkeeperExtension.class)
class BlockPlacementIT
{
    @Test
    void placeBlock_shouldUpdateWorld(ILightkeeperFramework framework)
    {
        // setup
        var world = framework.worlds().main();
        var player = framework.bots().builder()
            .withName("lk_tester").atSpawn(world).build();

        // execute
        player.placeBlock("minecraft:stone", 1, 100, 0)
            .andWaitTicks(1);

        // verify
        assertThat(world).hasBlockAt(1, 100, 0)
            .ofType("minecraft:stone");
    }
}

Quickstart

Add the Maven dependencies

Start with this test project, or merge its configuration into your plugin’s POM. JitPack resolves both the test dependency and the build plugin. The Spigot API supplies Bukkit types used by assertions. Replace the example userAgent with your project and contact URL.

pom.xml · complete test project
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 https://maven.apache.org/xsd/maven-4.0.0.xsd">
  <modelVersion>4.0.0</modelVersion>
  <groupId>com.example</groupId>
  <artifactId>my-plugin-tests</artifactId>
  <version>1.0-SNAPSHOT</version>

    <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>

  </properties>

  <repositories>
    <repository>
      <id>jitpack.io</id>

    </repository>

      <id>spigotmc-snapshots</id>

  <dependencies>
    <dependency>
      <groupId>com.github.PimvanderLoos.LightKeeper</groupId>

      <scope>test</scope>

            <goals>
              <goal>integration-test</goal>

  </build>
</project>

Write a test. Use a real world.

Save this as src/test/java/FirstPassingTestIT.java. The extension starts the prepared server and injects the framework. This block assertion needs no fixture plugin.

FirstPassingTestIT.java
import nl.pim16aap2.lightkeeper.framework.ILightkeeperFramework;
import nl.pim16aap2.lightkeeper.framework.LightkeeperExtension;
import org.junit.jupiter.api.Test;
import org.junit.jupiter.api.extension.ExtendWith;
import static nl.pim16aap2.lightkeeper.framework.assertions.LightkeeperAssertions.assertThat;

@ExtendWith(LightkeeperExtension.class)
class FirstPassingTestIT
{
    @Test
    void placeBlock_shouldUpdateWorld(ILightkeeperFramework framework)
    {
        // setup
        var world = framework.worlds().main();
        var player = framework.bots().builder()
            .withName("lk_tester").atSpawn(world).build();

        // execute
        player.placeBlock("minecraft:stone", 1, 100, 0)
            .andWaitTicks(1);

        // verify
        assertThat(world).hasBlockAt(1, 100, 0)
            .ofType("minecraft:stone");
    }
}

Run it. Inspect the result.

With the POM from step 01 and an *IT.java test in place, run the full integration lifecycle.

Terminal
mvn verify
  1. pre-integration-test prepares a Paper server and writes the runtime manifest.
  2. Failsafe runs your test against that server, then verifies the result.
  3. Read test results in target/failsafe-reports/ and server logs under target/lightkeeper-server/.

Spigot is also supported; its first preparation builds the server with BuildTools. Cached builds are reused. Prefer the IDE gutter? Set it up →
