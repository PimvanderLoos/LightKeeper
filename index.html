import nl.pim16aap2.lightkeeper.framework.ILightkeeperFramework;
import nl.pim16aap2.lightkeeper.framework.LightkeeperExtension;
import org.junit.jupiter.api.Test;
import org.junit.jupiter.api.extension.ExtendWith;

import static nl.pim16aap2.lightkeeper.framework.assertions.LightkeeperAssertions.assertThat;

@ExtendWith(LightkeeperExtension.class)
class BlockPlacementIT
{
    @Test
    void placeBlock_shouldUpdateWorld(ILightkeeperFramework framework)
    {
        // setup
        var world = framework.worlds().main();
        var player = framework.bots().builder()
            .withName("lk_tester")
            .atSpawn(world)
            .build();

        // execute
        player.placeBlock("minecraft:stone", 1, 100, 0)
            .andWaitTicks(1);

        // verify
        assertThat(world).hasBlockAt(1, 100, 0)
            .ofType("minecraft:stone");
    }
}

/ Your first working test

Your first passing test.

Set up the Maven plugin and JUnit framework, write a test, and run it against a real Paper or Spigot server.

Quickstart

Run a complete plugin project.

The example builds a valid plugin, installs it on Paper and runs JUnit. Java 21 and Maven 3.9+ are required. You do not need to build LightKeeper itself.

git clone https://github.com/PimvanderLoos/LightKeeper.git
cd LightKeeper
mvn -f examples/single-module/pom.xml -Dit.test=GettingStartedIT verify

For your existing plugin, add the starter test dependency and Maven preparation plugin. Get the configuration →

Write a test. Use a real world.

Save this as src/test/java/example/GettingStartedIT.java. The extension starts the prepared server and injects the framework. The example installs its own plugin; this first world interaction checks the environment before you add assertions about your own commands or events.

GettingStartedIT.java
package example;

import nl.pim16aap2.lightkeeper.framework.ILightkeeperFramework;
import nl.pim16aap2.lightkeeper.framework.LightkeeperExtension;
import nl.pim16aap2.lightkeeper.framework.PlayerHandle;
import nl.pim16aap2.lightkeeper.framework.WorldHandle;
import org.junit.jupiter.api.Test;
import org.junit.jupiter.api.extension.ExtendWith;

import static nl.pim16aap2.lightkeeper.framework.assertions.LightkeeperAssertions.assertThat;

/** A complete first integration test; no commands or plugins from LightKeeper's internal fixtures are needed. */
@ExtendWith(LightkeeperExtension.class)
class GettingStartedIT
{
    @Test
    void placeBlock_shouldUpdateWorld(ILightkeeperFramework framework)
    {
        // setup
        final WorldHandle world = framework.worlds().main();
        final PlayerHandle player = framework.bots().builder()
            .withName("lk_tester")
            .atSpawn(world)
            .build();

        // execute
        player.placeBlock("minecraft:stone", 1, 100, 0).andWaitTicks(1);

        // verify
        assertThat(world).hasBlockAt(1, 100, 0).ofType("minecraft:stone");
    }
}

The standard configuration selects and installs your module’s packaged plugin automatically. Explore what you can test →

Run it. Inspect the result.

With the POM from step 01 and an *IT.java test in place, run the full integration lifecycle.

Terminal
mvn -f examples/single-module/pom.xml -Dit.test=GettingStartedIT verify
  1. pre-integration-test prepares the actual packaged plugin and captures immutable server inputs.
  2. Failsafe runs your test against that server, then verifies the result.
  3. Read test results in target/failsafe-reports/ and server logs under target/lightkeeper-server/.

Spigot is also supported; its first preparation builds the server with BuildTools. Cached builds are reused. Watch a production change make the test fail, then pass →
